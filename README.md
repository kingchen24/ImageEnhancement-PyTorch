# 基于多尺度特征增强的低质量图像重建与评价系统

针对手机拍摄、工业检测等场景中的噪声、模糊及压缩失真问题，构建图像增强与质量评价一体化框架，实现图像质量提升与自动评估。

## 系统架构

```
project/
├── config.py              # 全局配置
├── degradation.py         # 图像退化模型（噪声/模糊/压缩）
├── enhancement.py         # 图像增强算法（传统+深度学习）
├── evaluation.py          # 图像质量评价（PSNR/SSIM/MS-SSIM/VIF/FSIM/LPIPS）
├── automated_eval.py      # 自动化评测平台

├── train.py               # 训练流程

├── models/
│   ├── __init__.py
│   ├── msfe_net.py        # 多尺度特征增强网络

├── data/                  # 数据目录
```

## 核心功能

### 1. 图像退化模型

| 退化类型 | 方法 | 参数 |
|---------|------|------|
| 高斯噪声 | `add_gaussian_noise` | mean=0, std=25 |
| 椒盐噪声 | `add_salt_pepper_noise` | amount=0.02 |
| 泊松噪声 | `add_poisson_noise` | scale=1.0 |
| 高斯模糊 | `add_gaussian_blur` | kernel_size=7, sigma=1.5 |
| 运动模糊 | `add_motion_blur` | kernel_size=15, angle=30 |
| JPEG压缩 | `add_jpeg_compression` | quality=20 |
| 下采样 | `downsample` | scale=0.5 |

### 2. 图像增强算法

**传统方法:**
- 非局部均值去噪、双边滤波、中值滤波
- USM锐化、拉普拉斯锐化
- 双三次/Lanczos超分辨率
- CLAHE对比度增强

**深度学习方法:**
- MSFE-Net: 多尺度特征增强网络
  - U-Net风格编码器-解码器架构
  - 多尺度卷积并行特征提取
  - Channel Attention + Spatial Attention (CBAM)
  - ASPP多尺度上下文聚合
  - 残差学习策略

### 3. 质量评价指标

| 指标 | 说明 |
|-----|------|
| PSNR | 峰值信噪比 |
| SSIM | 结构相似性 |
| MS-SSIM | 多尺度结构相似性 |
| VIF | 视觉信息保真度 |
| FSIM | 特征相似性 |
| LPIPS | 感知图像块相似性 |

### 4. 损失函数

训练使用组合损失:
- Charbonnier Loss (L1平滑近似)
- SSIM Loss
- Perceptual Loss (VGG19)
- Gradient Loss (边缘保持)

### 阶段一：数据准备 & 退化模拟

**关键思路：** 项目不依赖真实配对数据集，而是从任意高清图像出发，用程序模拟真实世界的图像退化，生成「退化图 ⟷ 干净图」训练对。

| 退化类型 | 物理含义 | 实现原理 |
|----------|---------|----------|
| **高斯噪声** | 传感器热噪声、暗光拍摄噪声 | `np.random.normal(0, σ)` 叠加到像素值 |
| **椒盐噪声** | 传输错误、传感器坏点 | 随机位置置 0 或 255 |
| **泊松噪声** | 光子计数噪声（光子到达的量子特性） | `np.random.poisson()` 模拟信号依赖噪声 |
| **高斯模糊** | 镜头失焦、大气散射 | 2D 高斯核卷积，使用 `scipy.ndimage.gaussian_filter` |
| **运动模糊** | 拍摄时相机抖动或物体移动 | 按角度生成线状 PSF 核卷积 |
| **散焦模糊** | 景深外的虚化 | 圆盘状核（disk kernel）卷积 |
| **JPEG 压缩** | 社交媒体传输、存储压缩 | `cv2.imencode('.jpg', quality=20)` 模拟 DCT 量化失真 |
| **下采样** | 低分辨率设备拍摄后放大 | 先缩小再放大（bicubic），模拟 LR→HR 的退化过程 |

**可组合设计：** 退化流水线支持自由组合多种退化，例如同时施加「高斯噪声 + 运动模糊 + JPEG 压缩」，更接近真实手机拍摄的退化链路。

### 阶段二：图像增强（传统 + 深度学习双路径）

#### 路径 A：传统 CV 方法（无训练，即插即用）

| 操作 | 方法 | 原理简述 | 适用场景 |
|------|------|---------|---------|
| 去噪 | **NLM（非局部均值）** | 利用图像自相似性，加权平均相似块 | 高斯噪声 |
| 去噪 | **双边滤波** | 空间域+像素值域双重加权，保边 | 保留边缘的去噪 |
| 去噪 | **中值滤波** | 窗口内取中位数，非线性 | 椒盐噪声 |
| 去噪 | **小波阈值** | DWT 分解→软阈值→逆变换 | 频域去噪 |
| 锐化 | **USM** | 原图 + α×(原图 - 高斯模糊) | 通用锐化 |
| 锐化 | **拉普拉斯** | 二阶导数增强边缘 | 边缘增强 |
| 对比度 | **CLAHE** | 自适应直方图均衡（分块+限制对比度） | 局部对比度提升 |
| 超分 | **Bicubic/Lanczos** | 插值放大 | 传统上采样 |

#### 路径 B：深度学习模型 MSFE-Net（核心创新）

**网络结构详解：**

```
输入 [B,3,H,W] 归一化到 [-1,1]
  │
  ├─ InputConv: 3→64, 3×3
  ├─ MultiScaleConv: 并行 1×1, 3×3, 5×5, 7×7 → 拼接 → 64 通道
  │
  ├─ Encoder (3级下采样, 2× stride conv):
  │    enc1: 64→128   skip保存
  │    enc2: 128→256  skip保存
  │    enc3: 256→512  skip保存
  │
  ├─ Bottleneck (最底层):
  │    ResidualBlock → ASPP (dilation=6,12,18 + global pooling) → ResidualBlock
  │
  ├─ Decoder (3级上采样, bilinear + skip连接):
  │    dec3: 512+256(skip) → 256  + CBAM注意力
  │    dec2: 256+128(skip) → 128  + CBAM注意力
  │    dec1: 128+64(skip)  → 64   + CBAM注意力
  │
  └─ OutputConv: 64→64→3 (Tanh) → 残差连接 x + residual → clamp[-1,1]
```

**五个关键设计及选型理由：**

| 设计 | 作用 | 为什么这样设计 |
|------|------|---------------|
| **U-Net 编码-解码** | 多尺度特征提取 | 下采样增大感受野，上采样恢复分辨率，skip 连接保留高频细节 |
| **多尺度卷积（1/3/5/7核）** | 并行多感受野 | 小核捕获纹理，大核捕获结构，并行处理避免信息丢失 |
| **CBAM 注意力** | 通道+空间双重聚焦 | 通道注意力关注「哪些特征重要」，空间注意力关注「哪里重要」，参数量仅增加约 2% |
| **ASPP 瓶颈** | 多尺度上下文聚合 | 空洞卷积（dilation=6/12/18）在不下采样的前提下扩大感受野，全局池化补充全局信息 |
| **残差学习** | 输出残差 `x + res` | 模型只需学习噪声/模糊的残差分量，收敛更快，避免恒等映射退化 |

> 💡 **面试追问：为什么用 InstanceNorm 而非 BatchNorm？**
> 图像增强属于 image-to-image translation 任务，BN 的 batch 统计量在不同输入图之间耦合，会导致单张图推理时 batch 统计量不稳定。IN 对每个样本独立归一化，更适合 Low-Level Vision 任务（参考 U-Net、SRGAN 中的实践）。

> 💡 **面试追问：Tanh 输出 + 残差连接的设计意图？**
> Tanh 输出范围 [-1, 1]，与输入归一化区间一致。残差连接 `x + residual` 使模型学习的是输入与目标之间的差异量，这比直接预测干净图像更容易优化——因为在退化不严重时，残差接近 0，模型天然能输出接近输入的结果。

> 💡 **面试追问：为什么用 LeakyReLU (0.2) 而非 ReLU？**
> ReLU 在负半区梯度为 0，可能导致神经元永久失活（dying ReLU）。图像增强任务中负值特征同样重要（例如负的高频分量），LeakyReLU 保留负半区的小梯度，避免了信息丢失。

### 阶段三：质量评价体系

**为什么需要多指标？** 单一指标各有局限——PSNR 只看像素误差，SSIM 看结构，LPIPS 看感知质量。多维评价更客观。

| 指标 | 全称 | 度量什么 | 越高/越低好 | 计算复杂度 |
|------|------|---------|------------|-----------|
| **PSNR** | Peak Signal-to-Noise Ratio | 像素级均方误差的对数形式 | ↑ 越高越好 | O(N) 极低 |
| **SSIM** | Structural Similarity | 亮度 + 对比度 + 结构三要素 | ↑ 越高越好 | O(N) 低 |
| **MS-SSIM** | Multi-Scale SSIM | 在多个尺度上计算 SSIM 再加权融合 | ↑ 越高越好 | O(N log N) 中 |
| **VIF** | Visual Information Fidelity | 信息论角度，退化/增强前后的互信息比 | ↑ 越高越好 | O(N) 中 |
| **FSIM** | Feature Similarity | 相位一致性 + 梯度幅值的相似度 | ↑ 越高越好 | O(N log N) 高 |
| **LPIPS** | Learned Perceptual Similarity | 感知距离（模拟人眼判断） | ↓ 越低越好 | O(N) 中 |

> 💡 **面试追问：SSIM 的三要素分别是什么？公式怎么写？**
>
> **SSIM(x,y) = [l(x,y)]^α · [c(x,y)]^β · [s(x,y)]^γ**
>
> - **亮度 (luminance):** `l = (2μxμy + C1) / (μx² + μy² + C1)`
> - **对比度 (contrast):** `c = (2σxσy + C2) / (σx² + σy² + C2)`
> - **结构 (structure):** `s = (σxy + C3) / (σxσy + C3)`
>
> 其中 C1, C2 是防止除零的稳定常数：`C1 = (K1·L)²`, `C2 = (K2·L)²`, K1=0.01, K2=0.03, L=255。

> 💡 **面试追问：PSNR 和 SSIM 矛盾时以哪个为准？**
> PSNR 对像素误差敏感但对结构变化不敏感（例如平移一个像素，PSNR 骤降但人眼几乎无感）。SSIM 更贴近人眼感知。实际中两个都报，同时引入 LPIPS（基于神经网络的感知距离）作为仲裁。

> 💡 **面试追问：LPIPS 的实现原理？**
> 原始 LPIPS 使用预训练 AlexNet/VGG 提取多层特征，计算参考图和测试图在各层特征空间的 L2 距离，再通过学习的权重线性组合。本项目简化版用多尺度 Sobel 梯度特征代替，在无 PyTorch 依赖时也可快速评估。

### 阶段四：训练策略

| 组件 | 选择 | 理由 |
|------|------|------|
| **优化器** | AdamW | Adam 的改进版，权重衰减与自适应学习率解耦，正则化效果更好 |
| **学习率调度** | StepLR (每 30 epoch ×0.5) | 阶段性降低学习率，先大步收敛再小步精调 |
| **数据增强** | 随机裁剪 (128×128 patch) | 扩大有效数据量，且符合全卷积网络对输入尺寸灵活的特点 |
| **归一化范围** | [-1, 1] | 与 Tanh 输出范围一致，数值稳定性好 |
| **数据集** | 从高清图合成退化对 | 无需人工标注配对数据，数据获取成本极低 |

### 损失函数详解

训练使用**四种损失的加权组合**，各司其职：

```
Total Loss = 1.0 × Charbonnier L1  (像素级保真)
           + 0.5 × SSIM Loss       (结构保持)
           + 0.1 × Perceptual Loss (语义感知)
           + 0.05 × Gradient Loss  (边缘锐度)
```

| 损失项 | 直观理解 | 为什么不是纯 L1/L2？ |
|--------|---------|---------------------|
| **Charbonnier Loss** | `√(Δx² + ε²)` — L1 的平滑版 | L1 在零点不可导（梯度不连续），L2 对离群值平方惩罚过大。Charbonnier 取两者之长 |
| **SSIM Loss (1-SSIM)** | 最大化结构相似性 | 纯 L1 会产生模糊输出，SSIM 惩罚结构失真 |
| **Perceptual Loss (VGG19)** | 比较 VGG 中间层特征差异 | 捕获高层语义一致性，避免「数值好但看起来假」 |
| **Gradient Loss** | 比较水平和垂直梯度差异 | 约束边缘锐度，防止去噪/去模糊后图像变糊 |

> 💡 **面试追问：Perceptual Loss 为什么用 VGG19 而不用 ResNet？**
> VGG 在图像生成/增强社区是事实标准（参考 SRGAN、ESRGAN）。原因：VGG 的特征空间更规整，不同层的特征有明确的纹理→语义层次。ResNet 的跳跃连接使特征空间的几何特性更复杂，不适合做感知距离度量。

### 阶段五：自动化评测 & 报告

```
批量处理 → 逐图评价 → 汇总统计 → 生成报告(HTML/Markdown/JSON) + 对比图
```

报告包含：PSNR/SSIM 退化前后对比、提升百分比、处理时间、可视化对比图。

## 三、核心技术难点 & 解决方案

### 难点 1：真实退化链路的复杂性

**问题：** 真实低质量图像的退化是多种因素叠加（暗光噪声 + 手抖模糊 + 社交压缩），单一退化模拟不足以覆盖。

**解决方案：** 设计**可组合退化流水线** (`apply_degradation_pipeline`)，通过配置字典灵活组合多种退化。训练时随机选择退化组合，增强模型的泛化能力。这实际上是一种**数据增强策略**——模型见过更多退化模式后，对未见过的退化也有鲁棒性。

```
# 训练时可能的退化组合（从config动态选择）
Config A: [高斯噪声 std=15] + [高斯模糊 σ=1.0]
Config B: [椒盐噪声 0.01] + [运动模糊 angle=45°] + [JPEG q=30]
Config C: [泊松噪声] + [散焦模糊 r=3] + [下采样 0.5]
```

### 难点 2：多尺度信息的有效融合

**问题：** 图像退化在不同尺度表现不同——噪声是高频、模糊是中低频、压缩块效应是块级。单一感受野的卷积难以同时处理。

**解决方案：** 三层多尺度设计——
1. **输入层 MultiScaleConv：** 1×1、3×3、5×5、7×7 四种卷积核并行提取特征后拼接，覆盖不同感受野
2. **瓶颈层 ASPP：** 空洞卷积在不下采样的情况下，以不同 dilation rate 捕捉不同尺度的上下文
3. **编码-解码层 skip 连接：** 将编码器各层的多尺度特征直接传递到解码器，避免信息丢失

### 难点 3：增强图像的边缘模糊问题

**问题：** 去噪和去模糊操作常常导致图像边缘变模糊（over-smoothing）。L1/L2 损失倾向于输出「平均」结果，不利于保留锐利边缘。

**解决方案：** 三管齐下——
1. **残差学习：** 模型只学习退化分量，原始信号通过 skip 连接直接传递
2. **Gradient Loss：** 显式约束水平和垂直梯度与目标一致，数学上等价于对边缘的高频分量施加监督
3. **CBAM 空间注意力：** 让模型自动关注边缘等高频区域，分配更多计算资源

### 难点 4：Windows 中文路径支持

**问题：** `cv2.imread()` / `cv2.imwrite()` 不支持含中文的路径（OpenCV 的 C++ 底层使用 `char*`，多字节编码在 Windows GBK 环境下失败）。

**解决方案：** 编写 `utils.py` 中的 `imread()` / `imwrite()` 包装函数——使用 `np.fromfile()` 读取二进制数据再用 `cv2.imdecode()` 解码，写入时用 `cv2.imencode()` 编码再 `tofile()` 写入。绕过了 OpenCV 的路径编码限制。

```python
# 核心思路（已在 utils.py 实现）：
def imread(path):
    return cv2.imdecode(np.fromfile(path, dtype=np.uint8), cv2.IMREAD_COLOR)

def imwrite(path, img):
    ext = os.path.splitext(path)[1]
    cv2.imencode(ext, img)[1].tofile(path)
```

### 难点 5：评价指标的鲁棒性

**问题：** scikit-image 等依赖库在部分环境下不可用，且大尺寸图像计算 VIF/FSIM 耗时严重。

**解决方案：**
1. **纯 NumPy SSIM 回退：** 当 `skimage` 不可用时，自动切换到自定义的纯 NumPy 实现
2. **LPIPS 轻量化：** 不引入完整的 AlexNet 推理管线，改用多尺度 Sobel 梯度特征作为感知距离的近似代理
3. **异常保护：** 所有指标计算包裹在 try-except 中，单个指标失败不影响其他指标

### 难点 6：训练数据不足

**问题：** 获取大量真实的「低质量-高质量」配对图像成本极高，且不同设备/场景的退化模式各异。

**解决方案：** 采用**自监督合成策略**——从任意高清图出发，通过退化模型合成低质量版本，构成训练对。每 epoch 使用随机裁剪的 128×128 patch，每张图生成 16 个 patch，有效扩增数据量。这与 N2N (Noise2Noise)、NAFNet 等 SOTA 方法的训练策略一致。

## 五、面试常见追问速答

<details>
<summary><b>Q1: 为什么不用 Transformer/扩散模型？</b></summary>

CNN 方案对于 128×128 的 patch 训练已经足够。Transformer（如 Restormer）需要更多计算资源和数据，且本项目定位是「实用的一体化方案」。扩散模型虽然生成质量高，但推理速度慢（需要多步去噪），不适合批量处理。这是**性能与效率的权衡**。

</details>

<details>
<summary><b>Q2: 如何验证模型的泛化能力？</b></summary>

1. 训练时退化配置用随机参数（如噪声 std 在[15,35]采样），避免过拟合特定退化
2. 测试时使用训练中未见过的退化组合
3. 通过自动化评测平台 (`automated_eval.py`) 批量测试并生成报告
4. 传统方法作为 baseline，DL 方法必须超越传统方法才算有效

</details>

<details>
<summary><b>Q3: 如果部署到移动端如何优化？</b></summary>

1. 使用 MSFE-NetLite（参数量仅 1.2M）
2. TorchScript/ONNX 导出 → 移动端推理框架（NCNN/MNN/TNN）
3. INT8 量化：将 FP32 权重转为 INT8，精度损失 <1% 但速度提升 2-4×
4. 知识蒸馏：用大模型教小模型，保持精度的同时减小模型

</details>

<details>
<summary><b>Q4: 传统方法和 DL 方法各自的优劣势？</b></summary>

| | 传统方法 | DL 方法 |
|---|---|---|
| 推理速度 | 快（无 GPU 也可） | 需要 GPU 才能高效 |
| 泛化性 | 针对特定退化效果好 | 对混合退化鲁棒 |
| 上限 | 受限于手工设计的先验 | 数据驱动，上限更高 |
| 可解释性 | 强（数学原理清晰） | 弱（黑盒） |
| 适用性 | 已知退化类型的场景 | 未知/复杂退化场景 |

</details>

<details>
<summary><b>Q5: 这个项目最大的技术亮点是什么？</b></summary>

**不是单一技术的堆砌，而是完整闭环的工程能力：**
1. 退化→增强→评价→报告的**全链路打通**
2. 传统方法 + 深度学习的**双路径设计**，可对比可互补
3. 多尺度模块 (MultiScaleConv + ASPP + U-Net) 的**三层金字塔设计**
4. 四种损失的**加权组合**（像素+结构+感知+梯度），覆盖图像质量的多维度
5. 从训练到部署的**完整工程化考虑**（轻量版模型、纯 NumPy 回退、中文路径兼容）

</details>

## 六、一句话总结

> 这是一套**从数据合成、模型设计、训练策略、评价体系到自动化报告**完整闭环的低质量图像增强系统。核心思想是「多尺度特征提取 + 残差学习 + 复合损失约束」，以 U-Net 为基础骨架，通过 MultiScaleConv、ASPP、CBAM 三大模块在三个维度上增强多尺度表达能力，最终在像素精度、结构保持、感知质量和边缘锐度四个维度上同时优化。
